# Spotify Battle Frontend

React + Vite frontend for the Spotify Battle app.

## Development

```bash
# Install dependencies
npm install

# Start dev server (proxies API to localhost:8080)
npm run dev

# Build for production (outputs to ../web/dist)
npm run build
```

## Features

- Mobile-responsive design
- Album and Playlist search
- Pairwise voting system
- Results export as PNG
- Social sharing (Twitter, Bluesky, Mastodon, Instagram)
- LocalStorage persistence

## Tech Stack

- React 18
- Vite
- Vanilla CSS (no UI framework for minimal bundle size)
